# SQL Developer Internship | Task 3: Writing Basic SELECT Queries

## 📌 Project Overview
This repository contains the deliverables for **Task 3: Writing Basic SELECT Queries** as part of the Elevate Labs SQL Developer Internship. The primary objective of this task is to demonstrate a clear understanding of how to extract, project, filter, and sort data from a database using standard SQL commands.

### 🎯 Objectives
* Extract data from one or more database tables.
* Apply data filtering and restriction techniques.
* Sort and limit query outputs effectively

### 🛠️ Tools Used
* **Database Management System:** DB Browser for SQLite / MySQL Workbench
* **Language:** SQL

---

## 📂 Deliverables
1. **`sql3.sql`**: An SQL script showcasing the practical application of `SELECT`, `WHERE`, `ORDER BY`, and `LIMIT`.
2. **Conceptual Q&A**: Detailed explanations of core SQL concepts (detailed below).
